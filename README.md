# cat-fetch
this is a python script to display a random ascii art of a cat on your terminal  

has windows and unix-support 

to run this you need to first download dependencies which are all in the requirement.txt file you just run : 
```
pip install -r requirements.txt 
```
or if you are like me in linux you could set up a venv env :
``` 
python -m venv your_name_of_choice/
```
``` 
source your_name_of_choice/bin/activate
```
if you're for example on fish or zsh then you need to add that after activate :
```
source your_name_of_choice/bin/activate.fish
```
then after that you run the pip command
